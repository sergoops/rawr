# vivo S50 stock camera capability matrix

Build `PD2527_A_16.0.19.12.W10` (V2527A, Android 16). Evidence paths are
relative to `tmp/vivo-stock/PD2527_A_16.0.19.12.W10/`. This matrix records what
the stock camera does, what the public Camera2 surface exposes, and whether a
normal third-party app can reproduce the feature. It is the input to
`vivo-s50-60fps-decision.md`.

## Reading the verdicts

- `supported_by_public_api`: standard Camera2/CameraX API can request it, subject
  to the HAL's advertised capabilities.
- `needs_vendor_key`: a private `vivo.control.*`/QC key or hidden manager call is
  required; firmware-fragile and not a stable public contract.
- `needs_privileged_or_system`: only the stock/privileged camera app or a
  system-signed component gets the mode.
- `not_accessible`: no practical third-party path.
- `unknown`: evidence is insufficient; do not claim support.
